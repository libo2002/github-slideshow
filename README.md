# 基于最小二乘法的圆柱度误差评定算法

## 简介

本程序实现了基于最小二乘法的圆柱度误差评定算法，用于评估圆柱形零件的几何精度。程序包含完整的数据生成、算法实现和可视化功能。

## 主要功能

1. **数据生成**：模拟实际测量点数据，包含各种形状误差
2. **最小二乘拟合**：使用非线性最小二乘法拟合理想圆柱
3. **误差计算**：计算圆柱度误差值
4. **可视化展示**：多角度展示分析结果

## 文件说明

## 算法原理

### 1. 圆柱参数表示
圆柱由以下参数定义：
- 轴线中心坐标：(x₀, y₀)
- 轴线方向向量：(ax, ay, az)
- 圆柱半径：r

### 2. 最小二乘拟合
使用非线性最小二乘法优化目标函数：
```
min Σ(di - r)²
```
其中 di 是第i个测量点到圆柱轴线的距离。

### 3. 圆柱度误差计算
圆柱度误差定义为：
```
圆柱度误差 = max(残差) - min(残差)
```

## 程序结构

### 主要函数

1. **cylindricity_evaluation()** - 主函数，协调整个评定流程
2. **generate_test_data()** - 生成模拟测量数据
3. **fit_cylinder_least_squares()** - 最小二乘法拟合圆柱
4. **cylinder_residuals()** - 计算点到圆柱的残差
5. **calculate_cylindricity_error()** - 计算圆柱度误差
6. **visualize_results()** - 可视化结果

### 可视化功能

程序生成包含4个子图的综合分析图：

1. **3D点云与拟合圆柱**
   - 显示原始测量点
   - 显示拟合的理想圆柱面
   - 3D立体视图

2. **残差分布直方图**
   - 显示残差的统计分布
   - 标注均值和标准差
   - 评估数据质量

3. **残差沿轴向变化**
   - 显示残差沿Z轴的变化趋势
   - 识别系统性误差
   - 拟合趋势线

4. **误差统计信息**
   - 最小/最大残差
   - 平均残差和标准差
   - 最终圆柱度误差值

## 测试数据特征

程序生成的测试数据包含以下特征：
- 8个截面，每个截面16个测量点
- 轴线略有倾斜（模拟实际情况）
- 随机测量噪声
- 系统性形状误差：
  - 椭圆度误差
  - 锥度误差
