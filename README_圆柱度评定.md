# 基于最小二乘法的圆柱度误差评定算法

本程序实现了基于最小二乘法的圆柱度误差评定算法，适用于MATLAB 2024a。

## 功能特点

- ✅ 基于最小二乘法的圆柱面拟合
- ✅ 支持实际测量数据和模拟数据
- ✅ 完整的可视化结果展示
- ✅ 详细的误差分析报告
- ✅ 多种数据输入格式支持
- ✅ 符合ISO标准的圆柱度计算

## 文件说明

### 主要文件
- `cylindricity_evaluation.m` - 主程序文件
- `load_real_data_example.m` - 真实数据加载示例

### 输出文件
- `measurement_data.mat` - 测量数据文件
- `cylindricity_results.mat` - 评定结果数据
- `cylindricity_report.txt` - 文本格式报告

## 使用方法

### 1. 基本使用
```matlab
% 运行主程序
cylindricity_evaluation()
```

程序启动后会提示选择数据来源：
- 选择 `1`：生成模拟测量数据
- 选择 `2`：从文件读取实际测量数据

### 2. 使用真实测量数据

#### 方法一：准备CSV文件
创建名为 `measurement_points.csv` 的文件，格式如下：
```
X坐标, Y坐标, Z坐标
10.234, 5.678, 0.000
9.876, 6.123, 0.000
...
```

#### 方法二：准备Excel文件
创建名为 `measurement_points.xlsx` 的Excel文件，第一列为X坐标，第二列为Y坐标，第三列为Z坐标。

#### 方法三：准备文本文件
创建名为 `measurement_points.txt` 的文本文件，每行包含三个数值（X Y Z），用空格或制表符分隔。

#### 方法四：使用示例数据生成器
```matlab
% 生成示例测量数据文件
load_real_data_example()
```

### 3. 数据要求

- **坐标系统**：建议使用毫米(mm)作为单位
- **测量点分布**：应在圆柱表面的不同高度和角度位置进行测量
- **最少点数**：建议至少50个测量点以保证拟合精度
- **数据质量**：测量点应尽可能均匀分布在圆柱表面

## 算法原理

### 1. 最小二乘法圆柱拟合
程序使用非线性最小二乘法拟合理想圆柱面，优化参数包括：
- 圆柱轴线位置 (x₀, y₀)
- 轴线方向向量 (dx, dy, dz)
- 圆柱半径 r

### 2. 目标函数
最小化所有测量点到理想圆柱面距离的平方和：
```
min Σ(dᵢ - r)²
```
其中 dᵢ 是第i个测量点到圆柱轴线的距离。

### 3. 圆柱度误差计算
根据ISO 12180标准，圆柱度误差定义为：
```
圆柱度误差 = max(残差) - min(残差)
```

## 结果解读

### 1. 数值结果
- **圆柱轴线通过点**：拟合圆柱的轴线在XY平面的投影点
- **轴线方向向量**：圆柱轴线的方向（单位向量）
- **圆柱半径**：拟合得到的理想圆柱半径
- **圆柱度误差**：最大正偏差与最大负偏差之差
- **轴线与Z轴夹角**：评估圆柱的倾斜程度

### 2. 可视化结果
程序生成四个子图：
1. **3D散点图**：显示测量点和拟合圆柱面，颜色表示残差大小
2. **残差分布直方图**：显示测量误差的统计分布
3. **XY平面投影**：显示圆柱截面的拟合效果
4. **残差沿Z轴分布**：显示沿圆柱高度方向的误差变化

### 3. 报告文件
- **MATLAB数据文件** (`cylindricity_results.mat`)：包含完整的计算结果
- **文本报告** (`cylindricity_report.txt`)：包含主要参数和统计信息

## 技术参数

- **适用MATLAB版本**：MATLAB 2024a及以上
- **所需工具箱**：Optimization Toolbox
- **计算精度**：双精度浮点数
- **最大测量点数**：理论上无限制，建议不超过10,000点

## 注意事项

1. **数据预处理**：确保测量数据中没有异常值或重复点
2. **坐标系统**：所有测量点应在同一坐标系下
3. **测量范围**：测量点应覆盖圆柱的完整表面
4. **计算时间**：大量测量点可能需要较长的计算时间
